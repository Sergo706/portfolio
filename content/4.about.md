#intro
I’m a backend engineer working in the TypeScript and Node.js ecosystem, focused on identity, request security, threat-data processing, and developer infrastructure. I enjoy working close to the fundamentals of how systems behave under real constraints: request flows, state management, failure modes, observability, and the implementation details that determine whether software holds up under pressure. My public engineering work includes an interconnected authentication and request-security platform, offline threat-intelligence tooling, and a browser-native Git repository viewer. Before transitioning into engineering, I spent several years leading operations for a large hospitality business, managing teams, logistics, and risk in fast-moving environments. That experience shaped how I approach software: systems should be predictable, observable, and resilient because real users and real businesses depend on them.
